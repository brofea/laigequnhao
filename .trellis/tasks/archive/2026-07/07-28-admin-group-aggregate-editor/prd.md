# 完善群组聚合编辑

## 父任务

`.trellis/tasks/07-28-improve-admin-page`

## 目标

提供可创建、回显和原子保存群组主表、标签、加群方式及审核备注的响应式右侧抽屉，补齐管理员群组数据的完整 CRUD，同时保持版本冲突和软删除语义。

## 范围

- 新建与编辑共用右侧宽抽屉；窄屏向左扩展为全屏。
- 基本信息：标题、简介、性质、平台、业务状态。
- 标签：0–5 个，trim、去空、大小写不敏感去重、顺序可调。
- 加群方式：至少 1 条，允许多个同类型，完全重复项拒绝，顺序可调。
- 群号为非空文本；URL 只允许 `https:`；二维码使用 QR 子任务提供的 asset 引用契约。
- 平台切换后明确显示不兼容项并阻止保存，不静默删除。
- 联系方式只读且空值显示“未提供”；审核备注可编辑。
- 草稿整体保存；群组、标签、加群方式、审核备注使用 D1 batch/transaction 语义原子写入。
- 更新使用 `version` 并在冲突时不修改任何关联行。
- 修复现有“新建群聊”没有调用 create 的缺口。
- 回收站没有编辑入口；恢复后才能编辑。
- dirty guard、焦点管理、错误回显和列表权威回写。

## 不在范围

- 管理员列表筛选、搜索、排序的实现。
- QR asset migration、R2 清理状态机和公开二维码对话框。
- 联系方式编辑、操作历史、批量编辑和导入导出。

## 依赖与约束

- 依赖 `.trellis/tasks/07-28-qr-resource-public-flow` 先稳定二维码 asset DTO/输入契约。
- 请求使用专用 create/update schema，不复用 `AdminGroupDto` partial。
- `submissionContact` 不得出现在写入命令。
- 所有不安全请求继续要求 CSRF。

## 验收标准

- [ ] 管理员可创建完整群组并在列表中看到权威返回值。
- [ ] 编辑抽屉正确回显全部可编辑字段，宽屏右侧、窄屏全屏。
- [ ] dirty guard 覆盖关闭按钮、遮罩、Escape 和导航。
- [ ] 0/5 个标签可保存，空值、第 6 个和重复标签被拒绝。
- [ ] 至少一个加群方式；多条同类型可保存，重复项和删除最后一项被拒绝。
- [ ] 平台不兼容、空群号、非 HTTPS URL 和无效 QR asset 返回字段错误并保留草稿。
- [ ] 联系方式只读，审核备注可写且两者不进入公开 API。
- [ ] 聚合写入全成功或全失败；version 冲突不修改标签、方式或 notes。
- [ ] 回收站没有编辑入口，恢复后保留原状态并可编辑。
- [ ] 创建/编辑成功后列表和滚动位置保持合理，不出现跳顶回归。
