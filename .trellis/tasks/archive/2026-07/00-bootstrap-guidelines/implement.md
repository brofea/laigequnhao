# 实施计划：来个群号

在用户通过后续消息明确审核并批准最终 PRD、技术设计和 Specs 摘要之前，不得开始实现。

## 实施顺序

1. **搭建应用骨架**
   - 使用 pnpm 创建 Vue 3 + Vite + 严格模式 TypeScript 项目。
   - 添加 Vue Router、Tailwind CSS、Hono、Zod、测试工具、lint、格式化和 `vue-tsc`。
   - 配置 Pages，确保只有 `/api/*` 调用 Functions。

2. **建立共享契约与配置**
   - 创建有类型约束的 `site.config.ts` 及其构建时校验。
   - 定义群聊性质、状态、加群方式、资源用途和 API 错误码的领域联合类型。
   - 定义 Zod 请求、响应、公开投影和管理员投影 schema。

3. **建立 Cloudflare 基础设施边界**
   - 添加 `wrangler.jsonc`，配置本地/预览 D1 和 R2 binding。
   - 添加初始 SQL migration 和 seed 测试夹具。
   - 记录所需 Secrets，并确保不存在生产环境默认值。

4. **构建 API 基础**
   - 创建 Hono `/api/v1` 应用，以及请求 ID、日志、校验、错误、认证、Origin/CSRF 和限流中间件。
   - 添加使用显式行映射的直接 D1 repository。
   - 添加公开群聊列表/搜索、提交和点赞路由。

5. **构建 MVP 首页**
   - 添加游标加载、确定性轮换、搜索 URL 状态、卡片列表、平台/性质徽章、标签、复制操作、加群方式操作和点赞切换。
   - 添加 Logo 兜底行为和非急切图片加载。
   - 添加受 Turnstile 保护的纯文本提交对话框。

6. **构建管理功能**
   - 添加登录、会话检查、退出登录、受保护路由行为和会话过期恢复。
   - 添加群聊/状态 CRUD、审核队列、软删除回收站、恢复和可重试的永久清理。

7. **构建图片处理**
   - 添加仅在浏览器处理的 WebP/PNG/JPG 输入和预览。
   - 添加 Logo 和二维码转换预设，并支持透明 PNG。
   - 在客户端和 API 两侧执行 100 KB 与 300 KB 上限。
   - 添加 R2 上传、不可变 key 替换和孤立对象清理行为。

8. **构建运行状态页面**
   - 添加相互独立的 API、D1 和 R2 健康检查。
   - 添加 D1 业务指标。
   - 添加 Cloudflare Web Analytics 查询，展示 24 小时、7 天和 30 天流量/性能面板。

9. **按顺序实施增强阶段**
   - 完善响应式体验。
   - 优化 UI/UX。
   - 添加跟随系统/手动切换的深色模式。
   - 完成 1,000 张卡片规模的性能优化。
   - 添加二维码展示/保存交互。

10. **完成质量与部署门禁**
    - 运行所有必需检查。
    - 验证本地、预览和生产 binding 相互隔离。
    - 验证生产构建和 Pages 路由。
    - 验证输出产物中不存在 Secret 和 API token。

## 验证命令

```bash
pnpm lint
pnpm format:check
pnpm typecheck
pnpm test
pnpm test:workers
pnpm test:e2e
pnpm build
pnpm exec wrangler pages functions build --outdir dist-functions
```

应用骨架搭建时可以调整具体 script 名称，但最终仓库必须为上述每项门禁提供一个稳定命令。

## 必需测试夹具

- 1,000 个带多种标签和加群方式的已发布/已下架群聊。
- 全部四种业务状态以及软删除记录。
- 位于 100 KB/300 KB 上限之下、恰好达到上限和超过上限的 WebP 夹具，包括带 alpha 透明通道的图片。
- 重复点赞、取消点赞、限流、会话过期、冲突和 D1/R2 部分清理场景。
- Cloudflare Analytics 成功、部分数据、超时和不可用场景。

## 高风险边界与回滚点

- **Schema migration**：破坏性变更前导出数据；使用补偿 migration，不得修改已经应用的 SQL。
- **认证**：在预览环境通过登录、过期、退出、CSRF 和限流检查之前，保留上一个生产部署。
- **资源替换/清理**：D1 引用指向新 key 之前，绝不删除旧 R2 对象。
- **公开投影**：字段变更前添加契约测试，防止泄漏私有提交数据。
- **轮换算法**：测试使用固定时钟，不得依赖机器时区。

## 开始实现前的审核门禁

- PRD 不存在阻塞性开放问题或过期决策。
- `design.md` 与最终 PRD 一致。
- `.trellis/spec/` 不含模板占位符。
- 前端、API、错误、数据库、日志和测试 Specs 对共享契约与校验边界的描述一致。
- 用户已经审核最终规划摘要，并在后续消息中明确批准开始实现。
