# 06 系统加固与发布验收

## 0. 任务信息

| 项目 | 内容 |

| 任务编号 | T06 |

T06 是最终质量和发布门禁，不是新的产品开发任务。它可以补充测试、配置、文档和最小跨任务集成修复，但不能借“加固”“优化”或“回归修复”重新设计冻结前端。

## 1. 任务目标

确认 T04 后端能力和 T05 真实业务适配组成的系统可以安全、稳定、可回滚地发布。验证范围覆盖公开端、管理端、API、数据库、R2、认证、权限、CSRF、性能、无障碍、响应式、视觉冻结、部署和运营文档。

## 2. 工作范围

### 2.1 测试体系

- 运行并补齐 Vitest。
- 运行并补齐 Workers Vitest。
- 运行并补齐 Playwright 公开端流程。
- 运行并补齐 Playwright 管理端流程。
- 运行视觉回归截图。
- 运行键盘、焦点、对比度和减少动态效果检查。
- 固定时间、时区、小时槽位、主题和数据夹具。
- 保留失败证据、环境和复现命令。

### 2.2 公开端回归

验证总 PRD 的公开流程：

- 默认首页区域顺序。
- 搜索 debounce、IME、URL 同步、清空恢复。
- 发现新群数量、排序和空状态。
- 标签统计、点击替换搜索词和空状态。
- 启用/关闭板块的公开边界。
- 空板块和单板块错误隔离。
- 所有群组 Grid、cursor、无限滚动和空状态。
- 搜索结果 Grid、cursor、无结果、失败和重试。
- 卡片摘要、点赞独立操作和键盘行为。
- 详情 Dialog、深链、返回、前进、分享和焦点。
- 多种加群方式、复制、二维码和打开链接。
- 下架、回收站、删除群组不可公开访问。
- 桌面、平板、手机、浅色和深色主题。

### 2.3 管理端回归

- 登录、会话恢复、退出和权限失败。
- 群组列表每页固定 50 条。
- 总数、总页数、边界 50/51 条。
- 搜索、状态、回收站和排序。
- URL 恢复、返回/前进、筛选回第一页。
- 删除当前页最后一条自动退页。
- 群组新建、编辑、脏表单、版本冲突。
- 图片上传、替换、失败和清理。
- 标签、平台、加群方式和状态变更。
- 回收站、恢复、永久删除和 R2 资源。
- 板块创建、编辑、启停、删除。
- 板块拖拽、排序模式和成员表格。
- 添加 published/unpublished、拒绝 trash。
- 成员上移、下移、移除关联。
- 空板块、零板块和错误回滚。
- 管理端窄屏表格、抽屉、焦点和滚动锁定。

### 2.4 安全检查

- 管理认证和会话 cookie。
- CSRF 防护。
- 管理员权限边界。
- Zod/输入校验。
- 版本冲突和突变令牌。
- 公开数据过滤。
- 详情深链不泄露不可公开群组。
- 速率限制和错误响应。
- 文件上传类型、大小和资源访问。
- R2 临时资源和删除策略。
- 日志不包含 session、token、私密链接或二维码内容。

### 2.5 性能检查

- 公开目录和搜索不全量返回。
- 管理端只取 50 条和所需总数。
- 发现新群最多 10 条。
- 标签为聚合查询。
- 板块成员无明显 N+1。
- 图片懒加载和固定比例不破坏布局。
- 首屏主题设置不等待 Vue 挂载。
- 小时随机不写数据库、不运行定时任务。
- 大板块管理表保持固定高度和内部滚动。
- API 慢请求、错误率和客户端重复请求可观测。

### 2.6 部署与迁移

- 构建可重复。
- 环境变量清单准确。
- D1 migration 可在演练库重复执行。
- 旧代码与新增 nullable schema 的兼容窗口明确。
- 新代码在 migration 未完成时有明确失败行为。
- 默认板块不重复创建。
- `last_published_at` 初始 NULL 得到验证。
- 失败迁移可恢复。
- 发布顺序和回滚步骤可执行。
- Workers、D1、R2、Analytics 配置核对。
- 健康检查、日志和监控可用。

### 2.7 发布文档

形成：

- 发布前检查表。
- 数据备份与迁移说明。
- 部署步骤。
- 环境变量说明。
- 健康检查。
- 回滚步骤。
- 失败升级处置。
- 监控指标和告警。
- 已知问题。
- 验收签字/确认记录。

## 3. 前端冻结规则

### 3.1 禁止

T06 不得修改：

- 页面结构。
- Vue 表现组件。
- CSS、Tailwind、主题 Token。
- 布局、颜色、字体、间距、圆角和阴影。
- 动画和响应式视觉规则。
- Dialog、Carousel、卡片、表格、抽屉和表单设计。
- 用户交互流程、按钮层级和导航语义。
- prototype v2 或其截图基线。

### 3.2 允许

- 测试和测试工具。
- fixture、时间、时区、主题和浏览器配置。
- 部署/构建/监控配置。
- 发布、迁移、回滚和验收文档。
- 后端、API client、adapter 的必要集成修复。
- 不改变表现的错误处理和请求生命周期修复。

### 3.3 发现差异

视觉回归发现问题时：

1. 保存截图、环境和差异描述。
2. 说明是否由真实数据、adapter、API 或表现层引起。
3. 非表现问题可回派 T04/T05。
4. 表现问题只记录方案和发布风险。
5. 未获用户批准不得修改表现。

## 4. 不包含内容

T06 不包含：

- 新产品功能。
- 旧 T04-T10 的任何实施边界。
- 重新设计 prototype v2。
- 以测试为理由调整页面视觉。
- 大规模重构已验收模块。
- 删除失败测试、降低断言、取消视觉回归。
- 用生产数据替代可重复测试夹具。
- 忽略迁移失败或权限失败。
- 未经批准的性能“优化”导致行为变化。

## 7. 视觉与无障碍验收

### 7.1 截图基线

固定以下组合：

- 首页桌面浅色。
- 首页桌面深色。
- 首页手机浅色。
- 首页手机深色。
- 详情 Dialog。
- 管理群组列表。
- 板块管理。
- 管理抽屉。

固定浏览器、视口、数据、时间、时区、系统主题和字体加载。时间随机和小时随机必须可控。

### 7.2 无障碍

- 键盘完成核心流程。
- 焦点可见。
- Dialog 焦点锁定和恢复。
- 图标按钮可访问名称。
- 颜色不是唯一状态。
- 浅色/深色对比度合理。
- 触摸目标可操作。
- 支持 reduced motion。
- Toast/Error 可被辅助技术感知。
- 表格表头和单元格语义正确。

## 8. 安全验收标准

- [ ] 无匿名管理写入。
- [ ] 无 CSRF 绕过。
- [ ] 无越权读取非公开数据。
- [ ] 无通过详情深链泄露删除对象。
- [ ] 无通过错误信息泄露内部字段。
- [ ] 输入超限被拒绝。
- [ ] 版本冲突可检测。
- [ ] 突变令牌不可重放造成重复动作。
- [ ] 上传限制和资源清理有效。
- [ ] 速率限制仍生效。
- [ ] 日志无凭证和私密加群信息。

## 9. 性能验收标准

- [ ] 公开列表不全量返回。
- [ ] 搜索不重复请求。
- [ ] 标签无 N+1。
- [ ] 板块无明显 N+1。
- [ ] 管理端固定 50 条。
- [ ] 首屏不因主题闪烁等待。
- [ ] 图片懒加载和固定比例。
- [ ] 大板块表格不无限撑高页面。
- [ ] 稳定随机不写数据库。
- [ ] 构建产物无生产 fixture。

## 10. 发布阻塞条件

下列任一项存在，T06 不得通过：

- 公开泄露下架、回收站或删除群组。
- 管理写操作缺认证、CSRF 或权限。
- 迁移不可重复或无回滚路径。
- T05 仍依赖生产 Mock。
- 关键公开或管理流程无法完成。
- 视觉冻结被未批准修改。
- 数据位置出现重复、丢失或部分更新。
- R2 资源出现不可控泄漏或误删。
- 关键自动化测试失败且无用户批准的延期。
- 部署健康检查或回滚不可执行。

## 12. Review 与 brainstorm 门禁

开始前必须重新读取总 PRD，并以联合视角审查：

- 产品：是否覆盖总 PRD 的真实用户流程和非目标。
- Staff Engineer：是否存在层间回归、部署风险、数据丢失或不可回滚。
- QA：每个验收项是否有可重复命令、夹具、环境和证据。

若视觉差异需要改表现层、测试环境无法稳定复现，或发布风险无法在当前边界内解决，先与用户 brainstorm；不自行扩大权限。
