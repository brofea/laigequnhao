# T03 实施记录：正式主项目视觉迁移与业务接入

## 当前决策

- `prototype/` 是唯一视觉真源且保持隔离零修改；正式 `src/` 机械迁移其 Vue 组件和 CSS，除文件名、路由、配置和业务数据适配外不改变表现。
- 公开首页只承载公开群组发现、搜索、点赞、复制、详情和投稿。
- `/admin/login` 是独立登录路由；`/admin` 是唯一管理页面。
- 管理页面内部只保留三个板块：群组管理、板块管理、运行数据。设计系统页面已移除。
- 群组发现、投稿、会话、管理员群组 CRUD、运行健康与统计接入现有 API；板块管理沿用当前已有的板块数据结构，等待对应正式后端契约时再替换本地状态。

## 已执行变更

- 正式入口改为 `#app` + Vue Router，路由为 `/`、`/admin/login`、`/admin`。
- 公共顶栏左侧只保留可配置品牌，右侧保留主题切换、可配置 GitHub 链接和公开投稿按钮；没有左侧管理端按钮。
- 接入系统主题三态、持久化和初始化防闪烁逻辑，继续使用浅色、深灰深色与系统偏好。
- 将 `prototype/components` 和 `prototype/styles/index.css` 迁移到正式 `src/components` 与 `src/styles`，保留首页、管理端三模块和原型 Dialog；移除未使用的旧视觉页面/静态统计组件。
- 管理端群组列表、筛选、排序、搜索、回收站、编辑、新建、软删除、恢复和永久删除使用现有 API 与认证/CSRF 会话。
- 运行数据板块读取现有健康检查与 Dashboard API。
- 公共投稿弹窗使用现有投稿 API；不会把板块或视觉样例数据当作正式群组数据层。
- 端到端测试改为覆盖正式首页、管理登录、三个管理板块、公开投稿弹窗和响应式板块操作，不再依赖旧顶栏或固定管理数据。
