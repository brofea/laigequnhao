## 1. 任务定位与联合 Review

T06 依赖 T02 已确认的 prototype 视觉基线、`t03-visual-migration` 的正式 `src/` 组件迁移和 T04 的群组 Contract/显示宽度规则，为 T07 首页与搜索提供真实数据驱动的 `GroupCard`、`HorizontalCarousel`、群组详情 Dialog、`?group=` URL 控制器和分享能力。

本 PRD 已从产品、Staff Engineer、QA 三个角度复核并冻结：

1. 发现新群、动态板块、所有群组和搜索结果必须复用同一套卡片和主要交互，不能各写一套。
2. 卡片只展示头像、标题、平台、简介摘要、点赞；不展示加群按钮、二维码、群号或分享按钮。
3. 卡片主体点击打开详情；点赞是独立操作，不能冒泡打开详情，并复用现有 device ID、localStorage、pepper/后端逻辑和错误回滚。
4. 卡片简介最多四行，标题最多两行；CSS 视觉截断不能修改原始数据，详情展示完整内容。
5. Carousel 基于原生横向滚动和 scroll snap，支持鼠标、触摸、触控板、必要时纵向滚轮转换、键盘、边界释放和拖动误触抑制；不自动轮播、不无限循环、不依赖重量级库。
6. Dialog 是正式可访问 Dialog，URL 的 `group` 查询参数是打开状态来源；页面内打开用 push，直接深链接关闭用 replace，保留其他 query。
7. 分享链接只包含 `group` 和正确的 canonical origin，不携带搜索词、页码、管理参数、CSRF 或会话信息。
8. 深链接只能读取当前公开群组；下架、回收站、删除、草稿、待审核和非法 ID 统一安全处理，不泄露内部状态。
9. 若当前没有公开详情读取能力，只允许补充按 ID 的最小只读详情接口，不借机实现板块、搜索或数据库改造。

## 2. 用户价值

- 用户在不同公开区域看到一致的群组信息和交互，不需要重新学习卡片行为。
- 用户可用鼠标、手势、触控板和键盘浏览横向内容，并在移动端同时看到至少两张卡片。
- 用户可以通过详情 Dialog 查看完整简介和多种加群方式，不离开当前页面。
- 用户可分享可复用的规范链接，收件人直接打开对应群组详情。
- 键盘用户、屏幕阅读器用户、减少动态效果用户和窄屏设备都能完成核心浏览/关闭/复制动作。

## 5. 组件与数据边界

### R06-01 GroupCard

卡片接受公开群组摘要、点赞状态/数量、布局或 loading 标识，通过事件触发详情和点赞；不直接读取 Router、请求 API 或保存另一套点赞状态。卡片在 Carousel 与 Grid 中保持相同信息顺序，只有宽度由容器控制。

### R06-02 卡片内容

固定展示头像、标题、平台、简介摘要、点赞按钮和数量；不展示群号、链接、二维码、加群按钮、分享、完整标签或管理字段。标题最多两行，简介最多四行，均不改写原始字符串。

### R06-03 Carousel

`HorizontalCarousel` 不理解 Group、点赞或业务 API，只接受可访问名称、子项、滚动步长、按钮/状态配置。优先 CSS overflow-x、scroll-snap、原生触摸和受控滚动；一个容器级监听优于每张卡片全局监听。

### R06-04 Dialog

Dialog 接收当前 group ID、摘要占位、详情、点赞和请求状态；Router 状态由页面级 `useGroupDetailsRoute` 或等效控制器负责。Dialog 展示完整标题/简介、平台、点赞、多个加群方式、分享和关闭。

## 6. 交互需求

### R06-05 卡片点击与键盘

- 主体点击/Enter/Space 打开详情并更新 group query。
- 主体有可见 focus 和包含标题的可访问名称。
- 不嵌套 button；点赞 button 独立聚焦和触发。
- 点赞点击/键盘/触摸不打开 Dialog、不修改 URL；失败恢复状态和数量。

### R06-06 Carousel 操作

- 鼠标拖动超过可测阈值后滚动，并抑制当前手势的一次卡片点击；后续点击恢复。
- 触摸采用原生横向滚动，纵向手势仍能让页面上下滚动。
- 触控板横向滚动保留原生 deltaX；纵向 Wheel 只在有溢出、中间位置、非 Dialog/缩放时转换。
- 左右边界释放页面滚动；无溢出不拦截、不显示误导控件。
- 左右键、可选 Home/End、箭头按钮和 scroll snap 规则一致。
- 手机标准宽度至少同时看到两张卡片；不自动播放、不无限循环。

### R06-07 Dialog 与 URL

- 卡片打开采用 `router.push`，点击返回关闭，前进重新打开。
- 直接 `/?group=id` 打开后关闭采用 `router.replace` 清除 group，仍留在站内。
- 与 `q` 或其他合法 query 共存时只增删 group，不破坏其他状态。
- 同一 ID 不重复 push/请求；快速点击不同 ID 时旧请求不能覆盖新 URL。
- 无效/不可公开/不存在 ID 显示安全反馈、可关闭、清除参数，背景页面仍可用。

### R06-08 详情与加群方式

- 卡片摘要不足时 Dialog 打开加载 Skeleton，再按 ID 请求公开详情；不预加载全量敏感信息。
- 展示完整纯文本简介、平台、点赞和按管理员顺序的一个或多个加群方式。
- QR/复制/链接复用现有安全能力、Toast、协议校验和焦点返回。
- 加群方式异常不会阻断其他方式；详情失败可重试/关闭，不显示空白。

### R06-09 焦点与滚动

- 打开保存触发元素，焦点移入正式 Dialog，Tab/Shift+Tab 留在 Dialog。
- 关闭按钮始终可见；Escape 先关二级 QR，再关详情；遮罩仅内容外关闭。
- 关闭恢复触发卡片或深链接场景的搜索框/主内容焦点。
- 锁定背景滚动，恢复原位置且不明显跳宽；移动端处理 iOS/Android、安全区、软键盘和低高度横屏。
- 尊重 `prefers-reduced-motion`，功能不因禁用动画而消失。

## 7. 响应式与视觉

- 卡片标题、简介、点赞区域在长 ASCII、中文、Emoji、超长连续字符串和大点赞数下不破坏布局。
- 图片固定尺寸/占位，懒加载且失败不改变卡片高度。
- Dialog 桌面遵循最大宽度，手机接近全屏、内容区滚动、底部操作/安全区可触达。
- 卡片、Carousel、Dialog、遮罩、Focus、Skeleton、QR 和错误状态全部使用 T03 Token，浅色/深色/系统主题一致。
- 不对头像/QR 反色，不用硬编码颜色绕过主题。

## 8. 公开数据安全

- 公开详情只允许当前 `published` 且未删除/回收站记录；按 ID 知道路径也不能绕过过滤。
- 非公开状态统一“不可查看/不存在”语义，不区分下架原因或内部状态。
- DTO 不含 version、管理状态、R2 key、device hash、审核备注、删除信息或未公开字段。
- 分享链接不带 q、页码、筛选、CSRF、会话或调试参数。
- 纯文本简介不作为未经清洗 HTML 注入；外链使用协议白名单和必要 rel。
