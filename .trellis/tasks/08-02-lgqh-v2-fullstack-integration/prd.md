# 05 全栈业务适配

## 0. 任务信息

| 项目 | 内容 |
| --- | --- |
| 任务编号 | T05 |

旧任务中任何“重构首页”“重做卡片”“实现板块页面”“统一视觉”的内容均不属于本任务。页面、Dialog、布局和交互已经完成，T05 的工作是连接它们。

## 1. 任务目标

完成正式前端与 T04 真实后端能力的完整连接，移除生产路径中的 Mock 数据，让公开端和管理端在真实 API、真实认证、真实数据库、真实上传和真实错误条件下工作，同时保持 prototype v2 像素级一致。

## 2. 工作范围

### 2.1 Mock/fixture 清理

- 盘点正式应用的所有 API 入口、fixture、静态假数据和临时 fallback。
- 生产构建不得读取 `prototype/data` 或生产 fixture。
- 测试 fixture 只在测试边界注入，不进入生产 runtime。
- API 失败不能静默返回旧假数据。
- localStorage 只保留主题等已批准的客户端偏好，不存储业务真相。
- 记录每个删除或保留 Mock 的理由。

### 2.2 API client 与 DTO adapter

- 连接 T04 公开 API。
- 连接 T04 管理 API。
- 复用现有 request id、错误解析和认证机制。
- 将后端 DTO 映射到 T03 已存在的视图模型。
- 隔离后端字段变更和组件展示字段。
- 处理 null、空数组、缺省字段和分页结束。
- 处理取消过时请求和重复请求。
- 处理网络错误、超时、校验错误、冲突和权限失效。

### 2.3 公开端真实流程

在不改变视觉和交互的前提下连接：

- 默认首页。
- 主搜索框和 debounce 搜索。
- 中文输入法 composing 状态。
- 发现新群。
- 标签聚合。
- 启用板块及已发布成员。
- 所有群组 cursor pagination 和无限滚动。
- 搜索结果 cursor pagination。
- 卡片详情 Dialog 数据。
- `?group=` 深链接。
- 浏览器前进/后退和关闭 Dialog。
- 多种加群方式。
- 分享规范链接。
- 匿名点赞。
- 提交新群组。
- 空状态、错误状态和重试。

### 2.4 管理端真实流程

在保持 T03 既有页面、抽屉、表格和交互的前提下连接：

- 登录、会话恢复和退出。
- 管理群组页码列表，每页固定 50 条。
- 搜索、状态、回收站、排序字段和方向。
- URL 状态恢复、前进/后退和筛选回第一页。
- 新建、编辑、保存和脏表单守卫。
- 图片上传、替换、失败和清理。
- 多种加群方式和标签编辑。
- 版本冲突提示和重试/刷新路径。
- 回收站、恢复和永久删除。
- 板块列表、创建、编辑、启停、删除。
- 板块顺序、排序模式和成员管理。
- 添加已发布/已下架群组，拒绝回收站。
- 成员上移、下移、移除关联。
- 分析/健康数据的现有真实连接。

### 2.5 状态接线

为 T03 已有表现状态提供真实数据：

- 初始加载。
- debounce 等待。
- 首次请求加载。
- 继续加载。
- 成功空数据。
- 区域级错误。
- 全局错误。
- 重试。
- 会话失效。
- 无权限。
- CSRF 失败。
- 输入校验失败。
- 版本冲突。
- 上传处理中。
- 上传失败。
- 保存成功。
- 删除确认后的成功和失败。

如果冻结前端没有对应状态，不得临时添加新 UI；应记录缺口并和用户 brainstorm。

## 3. 允许改动范围

### 3.1 允许改动

- `src/shared/api` 下的请求封装。
- feature API 模块。
- composable、store、query adapter 和 DTO mapper。
- 请求缓存、取消、重试和状态转换逻辑。
- 不改变视觉的路由 query 解析连接。
- 测试夹具、API mock server、类型和 adapter 测试。
- API 错误归一化和权限状态映射。
- 不改变表现的环境配置。

### 3.2 允许但需审查

若现有 `.vue` 文件只包含纯数据接线且不改变 template、style、class、交互流程，可在用户明确同意后进行最小改动；默认先通过 composable/adapter 解决。任何触及 template、style、布局、控件顺序、交互事件或视觉 class 的变更均视为禁止。

### 3.3 变更记录

每个适配改动记录：

- 原 Mock 来源。
- 新真实接口。
- DTO 映射。
- 空/错/冲突处理。
- 影响的冻结视图。
- 是否触及表现文件。
- 测试命令和结果。

## 4. 不包含内容

T05 不包含：

- 页面结构重排。
- Vue 表现组件重写。
- CSS、Tailwind class、颜色、间距、布局和断点修改。
- 主题设计或主题系统重写。
- Dialog、卡片、Carousel、表格、抽屉和表单设计修改。
- 改变用户交互流程、按钮层级或导航语义。
- 通过隐藏功能、改变文案布局、添加临时弹窗解决接口问题。
- 新增总 PRD 未批准的业务规则。
- 修改 T04 的数据库/服务端语义以绕过适配错误。
- T06 的最终性能、安全、部署和发布验收。

## 6. 数据接线规则

### 6.1 公开首页

默认搜索为空时，按 T03 既有结构显示顶栏、搜索、发现新群、标签、板块和所有群组。T05 只提供对应真实数据和状态，不调整区域顺序、卡片数量、间距或视觉文案。

### 6.2 搜索

- 输入经 debounce 后调用真实接口。
- composing 阶段不发无效请求。
- 新搜索取消或忽略旧请求结果。
- `q` 保留在 URL。
- 清空恢复首页。
- 搜索 API 使用 cursor。
- 结束、空结果、失败和重试都映射到既有 UI。

### 6.3 板块

- 只请求公开启用板块。
- 已下架成员不在公开结果中。
- 空板块进入既有空状态。
- 单板块失败不能覆盖整个首页成功区域。
- 小时随机顺序直接使用服务端稳定结果。

### 6.4 详情

- 请求 `group` 深链接对应的真实公开详情。
- 无效/不可公开只显示非敏感错误。
- 保留搜索词和其他 query。
- 关闭后只清除 `group`。
- 多种加群方式按服务端配置顺序显示。
- 分享链接不带无关搜索词。

### 6.5 管理页码分页

- 每页固定 50，不新增条数选择器。
- query state 与真实请求参数一致。
- 筛选/排序/搜索变化回到第一页。
- 删除当前页最后一项后回上一页。
- totalItems/totalPages 使用后端真实值。
- 排序不在前端重新排序破坏稳定性。

## 7. 权限与会话接线

- 登录成功后按既有流程进入管理端。
- 请求使用既有 cookie/session 机制。
- 写请求携带现有 CSRF 方式。
- 401/403 不显示私有详情，不伪造成功。
- 会话失效按既有界面表现处理。
- 版本冲突保留服务端错误和已有恢复流程。
- 上传失败不把临时资源误显示为已保存资源。
- 公开请求不携带或暴露管理凭证。

## 8. 错误处理规则

适配层将 T04 错误 code 映射为有限的前端状态类别：

| 服务端类别 | 适配结果 | 表现层约束 |
| --- | --- | --- |
| validation | 字段错误/表单错误 | 使用既有反馈，不新增布局 |
| unauthorized | 会话失效 | 使用既有登录/错误流程 |
| forbidden/CSRF | 权限错误 | 不隐藏服务端事实 |
| conflict | 版本冲突 | 使用既有冲突流程 |
| not-found/not-public | 不可用详情 | 不泄露状态 |
| network/timeout | 可重试错误 | 使用既有错误状态 |
| server | 通用失败 | 不展示内部堆栈 |

适配层不得依赖英文 message 文本判断错误类别；优先使用稳定 code。

## 11. Review 与 brainstorm 门禁

开始实施前重新读取总 PRD，并进行联合 Review：

- 产品：所有用户流程是否保持不变，真实数据是否覆盖所有区域。
- Staff Engineer：adapter 是否隔离 Contract，是否存在重复请求、竞态或错误 fallback。
- QA：成功、空、错、超时、权限、冲突和恢复是否都有可重复证据。

如果任一问题需要修改表现层，停止实现，带着复现和建议与用户 brainstorm；默认维持冻结。
