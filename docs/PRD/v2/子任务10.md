# 1. 背景

子任务 01–09 分别完成了：

1. 全量 Spec 与代码审计
2. 设计语言规范与视觉样例
3. 主题系统、设计 Token 与顶栏
4. 发布状态字段、字符宽度和数据库迁移
5. 板块后端服务与 API
6. 群组卡片、Carousel 与详情弹窗
7. 首页信息架构与搜索重构
8. 管理端板块管理与三页面整合
9. 管理端群组页码分页与响应式表格

各子任务已经拥有自己的局部测试和验收标准，但单任务测试不能完全证明整个 V2 系统已经可以发布。

跨任务集成仍可能出现以下问题：

* 首页和详情弹窗分别正常，但组合 URL 历史错误
* 板块后端过滤正确，但首页缓存泄露已下架成员
* 管理端群组移入回收站成功，但板块页面没有同步
* 主题系统单独正常，但 Dialog、二维码或统计图表深色模式不可读
* 管理分页正常，但三页面导航返回时丢失 URL 状态
* 迁移测试通过，但真实升级顺序导致旧代码短暂读取新字段失败
* 卡片和 Carousel 单独正常，但多个 Carousel 连续滚动时 Wheel 事件锁死页面
* 固定高度成员表可滚动，但与板块拖拽手柄产生交互冲突
* 公开端、管理端和共享 Contract 使用不同字段版本
* Playwright 单文件通过，但全量并行执行时存在数据污染或测试顺序依赖

因此，本任务必须以系统整体为验收对象，建立最终发布闸门。

# 8. 验收严重级别

所有发现的问题必须标记严重级别。

## 8.1 S0：数据或安全灾难

示例：

* 未授权访问管理数据
* CSRF 可绕过
* 已下架或回收站群组公开泄露
* migration 丢失数据
* 永久删除误删共享资源
* 板块删除误删群组
* 版本冲突静默覆盖
* 分享链接包含会话或安全参数

处理规则：

* 立即阻塞发布
* 必须修复
* 必须新增自动化回归测试

## 8.2 S1：核心功能不可用

示例：

* 首页无法加载
* 搜索无法使用
* 管理端无法登录
* 群组无法编辑
* 板块无法创建或排序
* 手机端无法关闭 Dialog
* 管理分页跨页重复或遗漏
* 深链接无法打开
* 回收站关联未清理

处理规则：

* 阻塞发布
* 必须修复
* 必须有回归测试

## 8.3 S2：重要体验或兼容问题

示例：

* 某浏览器 Carousel 滚轮异常
* 深色模式局部不可读
* 手机抽屉底部按钮被键盘遮挡
* 浏览器返回丢失搜索状态
* 某响应式阶段列隐藏错误
* 焦点恢复不正确

处理规则：

* 默认阻塞发布
* 只有明确证明不影响核心使用时，才能经用户或总任务批准延期

## 8.4 S3：非阻塞缺陷

示例：

* 边距轻微不一致
* 非核心动画略有差异
* 罕见状态文案不够理想
* 不影响操作的小范围视觉偏差

处理规则：

* 记录
* 可在本任务修复
* 未修复时必须进入后续问题清单
